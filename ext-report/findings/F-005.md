# F-005 — refused TEAM retirement writes outcome fields before returning

**VERIFIED.** Classes P and D. Two generated one-call inputs reproduce on engine baseline `7963e36968`.
Outcome spec § 2 row 31 requires the held-seat refusal before the first write. Section 6 says an error leaves
the record unchanged.

| Generated draw                                           | Single directive                                                                                  | Stored difference after v1 and v2 refuse                                               |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Laver Cup SINGLE_ELIMINATION, 8 positions and 7 entrants | Main round 2 position 1, RETIRED, side 2, 1–6 1–2                                                 | Retirement, winner, score strings and sets, and matchUp/structure/draw stamps          |
| TEAM FEED_IN_CHAMPIONSHIP, 8 positions                   | Consolation round 2 position 2, same RETIRED outcome, `disableAutoCalc` and exit propagation true | Retirement, winner, score, disabled auto-calc, side draw position, line-up, and stamps |

Both standalone modes return `ERR_EXISTING_POSITION_ASSIGNMENT`. Their actual stored hashes match the **changed**
post-call harvest hashes. Differential raises `OutcomePipelineDivergence` with
`v1 ERR_EXISTING_POSITION_ASSIGNMENT, v2 ok` and restores the initial hash.

Each input is duplicated in the harvest. The Laver Cup copies are parts 216 and 217 of the recorded TEAM walk,
and the feed-in championship copies are parts 294 and 295. The fixture files each preserve one copy and the exact
record patch. The repro retains each expected refusal code and grades the stored hash against the pre-call record, as § 6 requires. See `harvest-replay.json` for all four scenario IDs.

**Mechanism, verified against the engine source.** Row 31 reads the held-seat decision from the v2 view. It admits both inputs. With no owned result or refusal, the dispatcher invokes `runV1(stored)`. That writer changes the live record and then returns the placement error. This is one defect reached through both selectors. The differential message compares v2 admission with the writer’s returned refusal. The violated postcondition is established separately by comparing the initial and final stored hashes after an error. [Dispatcher](../../src/mutate/matchUps/matchUpStatus/setMatchUpStatus.ts) · [row 31](../../src/mutate/matchUps/outcome/refusals.ts) · [shared held-seat predicate](../../src/query/matchUp/heldSeatRefusal.ts)

**Exposure and disposition.** Moderate engine-contract defect. Direct callers and integrators that keep a live record after an error without rollback can observe the partial write. On the reviewed TMX path the local queue requests rollback and the remote payload requests it as well. CFS forwards the request’s flag and guards its storage write on queue success. In a control run, wrapping each saved directive in an `executionQueue` with rollback enabled preserved its refusal code and initial state hash in both standalone modes. Differential continued to flag the preflight disagreement. [Control results](F-005-rollback.json) This is scheduled v2 hardening. [TMX mutation request](https://github.com/CourtHive/TMX/blob/63d8867e/src/services/mutation/mutationRequest.ts) · [CFS queue and persistence](https://github.com/CourtHive/competition-factory-server/blob/da39230d/src/modules/factory/functions/private/executionQueue.ts#L154-L175)

**Recommended fix and acceptance.** Extend the pre-write held-seat check used by v2 row 31 to recognize these TEAM placements. The legacy admission path also uses the shared predicate, so verify its inputs at both call sites. Each standalone mode should return `ERR_EXISTING_POSITION_ASSIGNMENT` with the entire record unchanged, including when rollback is disabled. Differential should return the refusal without throwing. Use adjacent legal TEAM retirements as controls and run all three suites.
