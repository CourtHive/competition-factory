# Tournament Management eXperience

TMX is a comprehensive, open-source tournament management application built with the Competition Factory. It serves as both a production-ready tournament management system and a complete reference implementation for building factory-based applications.

## Quick Links

- **[Live Demo →](https://courthive.github.io/TMX)** - Try TMX online (runs from GitHub Pages)
- **[GitHub Repository →](https://github.com/CourtHive/TMX)** - Full source code
- **[Component Storybook →](https://courthive.github.io/courthive-components/)** - UI components used in TMX

## Quick Start

### For End Users

Visit the [live demo](https://courthive.github.io/TMX) and explore tournament management features.

### For Developers

Clone and run locally:

```bash
git clone https://github.com/CourtHive/TMX
cd TMX
pnpm install
pnpm start
```

TMX uses pnpm only (`npm` is refused); `pnpm start` runs the Vite dev server.

### For Documentation Readers

Start with the [TMX Overview](./tmx/overview.md) to understand the architecture, then explore specific features based on your interests.
