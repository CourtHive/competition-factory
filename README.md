# Competition Factory

This repository holds [`tods-competition-factory`](https://www.npmjs.com/package/tods-competition-factory), configurable
tournament operations for competition management.

- **The package** lives in [`packages/competition-factory`](./packages/competition-factory): its
  [README](./packages/competition-factory/README.md), [CHANGELOG](./packages/competition-factory/CHANGELOG.md),
  source and scripts.
- **Documentation and examples:** <https://courthive.github.io/competition-factory/>, built from
  [`documentation/`](./documentation).
- **Contributing:** [CONTRIBUTING.md](./CONTRIBUTING.md). The repository is a pnpm workspace: run `pnpm install` at the
  root.
- **License:** [MIT](./LICENSE).
