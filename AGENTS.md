# Repository Guidelines

## Required Repository Instructions

Read and follow [CLAUDE.md](./CLAUDE.md) before working in this directory. Its
repository guidance applies equally to agents that discover instructions through
`AGENTS.md`, including setup, commands, architecture, coding conventions, testing,
and contribution requirements.

`CLAUDE.md` is the maintained source of these instructions. Follow its referenced
documents and ecosystem standards, including their precedence rules. Read any
more specific instructions in the repository or subdirectory you are modifying.

## Maintaining This Guide

Update shared repository instructions in `CLAUDE.md`; keep this file as a pointer
so the two agent entry points continue to use the same guidance.
